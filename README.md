# Signal Lost

Signal Lost é um microgame 2D para navegador desenvolvido com JavaScript e Canvas 2D.

O jogador controla uma entidade digital responsável por recuperar fragmentos de sinal espalhados pela arena. A fase é concluída quando todos os fragmentos são coletados.

## Funcionalidades

- movimentação com WASD e setas direcionais;
- movimentação diagonal normalizada;
- múltiplos fragmentos coletáveis;
- detecção de colisão;
- contador de fragmentos;
- condição de conclusão da fase;
- gerenciamento básico de estado do jogo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas 2D
- ES Modules
- Git e GitHub

## Controles

| Ação | Teclas |
| --- | --- |
| Mover para cima | `W` ou `↑` |
| Mover para baixo | `S` ou `↓` |
| Mover para esquerda | `A` ou `←` |
| Mover para direita | `D` ou `→` |

## Como executar

O projeto utiliza módulos JavaScript e deve ser executado através de um servidor local.

Com o VS Code:

1. clone o repositório;
2. abra a pasta do projeto;
3. abra o `index.html`;
4. execute com a extensão **Live Server**.
